**August 6–7, 2025 · Hyderabad, India.**

KubeCon + CloudNativeCon India 2025 brought adopters and technologists from
the open source and cloud native communities to Hyderabad for two days of
keynotes, breakouts, lightning talks and the Solutions Showcase.

- [KubeCon + CloudNativeCon India 2025](https://events.linuxfoundation.org/archive/2025/kubecon-cloudnativecon-india/)
- [Schedule](https://kccncind2025.sched.com/)
- [Session recordings](https://www.youtube.com/playlist?list=PLj6h78yzYM2MEQTMX_LIOK1hrePHxLD6U)

## Sessions from end user organizations

The event published no end user track, so the sessions below are those whose
speakers listed an organization that meets the
[CNCF End User definition](https://www.cncf.io/enduser/#end-user-definition)
as their company in the official schedule: an organization that uses cloud
native technologies internally rather than selling or supporting them. They
include keynotes from Chitale Dairy, Expedia Group, Intuit, Nomura and Zepto
alongside talks from [CNCF End User members](/community/members) such as
Adobe, Allianz Technology, Flipkart, Goldman Sachs and Intuit, and from
adopters such as Amartha, Amway, Arcesium, Gen, Groupon, Kongsberg Digital,
Krom Bank Indonesia, MoEngage, Pegasystems, PepsiCo, REA Group, Siemens and
Zomato.
